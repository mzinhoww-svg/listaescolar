# Roteiro E2E da S00 (fundação)

Alvo: URL do preview da Vercel da branch `slice/S00-fundacao`. Ferramenta: agent-browser.

## Pré-requisito

Se o preview estiver protegido pela Vercel (Deployment Protection), siga `agent-browser skills get protected-vercel-deployments` para obter acesso. Nunca escreva o segredo de bypass neste arquivo nem no PR.

## Passos

```bash
PREVIEW_URL="<url do preview da Vercel>"

agent-browser open "$PREVIEW_URL"
agent-browser get title
agent-browser eval 'document.title'
agent-browser eval 'document.querySelectorAll("img[alt=\"ListaCerta\"]").length'
agent-browser is visible 'img[alt="ListaCerta"]'
agent-browser screenshot docs/superpowers/e2e/screenshots/S00-preview.png
agent-browser close
```

## Resultado esperado

- `get title` e `document.title` retornam `ListaCerta`.
- A contagem de `img[alt="ListaCerta"]` é maior ou igual a 1.
- `is visible` retorna `true` para o logo.
- Screenshot salvo em `docs/superpowers/e2e/screenshots/S00-preview.png` e anexado ao PR.
