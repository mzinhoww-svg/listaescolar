# S00 · Fundação do repositório · Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Projeto Next.js pronto (TypeScript strict, Tailwind com tokens da marca, Zod, ESLint, Prettier, Vitest, Supabase CLI local, Sentry, CI) com layout base ListaCerta e página inicial simples. Sem tabelas.

**Architecture:** Next.js App Router, Server Components por padrão. Tokens da marca em `docs/brand/tokens.json` viram variáveis CSS/Tailwind. Env validado por Zod em `lib/env.ts`. Sentry inicializado só quando `SENTRY_DSN` existe.

**Tech Stack:** Next.js (estável atual), React, TypeScript strict, Tailwind, Zod, Vitest + Testing Library, ESLint, Prettier, Supabase CLI, @sentry/nextjs, pnpm.

**Spec:** `docs/PLAN.md` (S00), `docs/SPEC.md` seção 1, `docs/brand/GUIA-DE-MARCA.md`, prancha `docs/brand/pranchas/Main.png`.

## Global Constraints
- TypeScript strict, sem `any`. Zod em toda fronteira. Componente com até 250 linhas.
- Tokens: Tinta #0F1B2D, Papel #F5F2EA, Branco tonal #FCFBF8, Verde Certo #2FCB86, Verde Fundo #0B6B4A, texto-2 #3A4658, texto-3 #5A6575, linha #E6E2D8, campo #ECE8DE. Raios: card 24, botão 999, campo 14. Fonte Plus Jakarta Sans (500, 600, 700, 800).
- Wordmark sempre em caixa baixa: "lista" peso 500, "certa" peso 800, letter-spacing -0.05em. Não redesenhar o logo: usar os SVG de `docs/brand/logos`.
- Nomes de env: os de `.env.example`. Chaves Supabase novas (`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY`). Nunca commitar `.env.local`.
- Nenhum nome de modelo de IA fixo no código.
- Scripts: `dev`, `build`, `typecheck`, `lint`, `test`, `db:start`, `db:reset`.

## Review Focus
- `.env.local` ausente ou incompleto não pode quebrar `pnpm build` nem `pnpm test` (env com Zod: erro claro só onde a variável é necessária, nunca na S00).
- `SENTRY_DSN` vazio: Sentry desligado, sem erro.
- Nenhum segredo em `NEXT_PUBLIC_*` além da publishable key e URL.
- Página inicial sem dado inventado (sem contagens, sem preços, sem parcerias).
- `pnpm db:reset` funciona com Docker rodando e não falha por falta de migrations.
